# 评测口径与结果依据

推荐每个截止日之后7天购买的不同商品。交易统计、协同训练和行为特征只读取截止日前数据。重复交易事件保留；共现构图单独按用户—日期去重商品。目录使用已知完整商品表，这是离线目录假设。

## 指标

- **候选Recall@K**：每名有真实购买的用户，其真实商品进入前K候选的比例，再对用户平均。
- **HitRate@K**：至少命中一件真实商品的用户数除以评测用户数。
- **MAP@12**：对用户计算前12位置命中时的累计精度之和，除以`min(真实不同商品数,12)`，再对用户平均。
- **Oracle MAP@12**：固定候选集合下，将命中商品理想排序得到的上限；不是模型实际分数。
- **候选内子组Recall@5**：完整冷候选列表排序后，某子组未来正例对进入前五的比例；分母只含已在候选池中的该子组正例对。

## 内容召回证据

原始依据为既有`M4_3_metrics.json`及`M4_3_FINAL.md`。每个截止日对零交互或1–5次历史交易商品形成内容候选；以用户最近12周最多5个不同购买商品为种子，以28天半衰期加权余弦相似度取最优值。固定50件内容候选预算，与同一行为候选集合去重取并集。

## 低频候选排序证据

原始依据为既有`F70_EXPLAINABILITY_AUDIT.md`，排序器F70是项目名称：57维已有特征加13维商品时效与趋势特征。四窗合计264个候选内未来正例对，零交互160对、低频104对，互斥且完备。

低频Top5命中从43对升至90对；零交互从22对降至16对。树分裂增益与TreeSHAP（行业通用树模型贡献解释方法）指出首末销售时间的重要性，但未删除特征并重训，因此不作为因果消融结论。

## 复核范围

`results.json`仅提取与展示结论相关的汇总字段。原报告、模型、逐用户候选及真实标签不随仓库发布；公开汇总可以检查算术和口径，但不足以独立重跑原实验。此处四窗是开发窗口，不能包装成未触碰测试集。整理仓库期间只运行合成样例和测试，不重新访问实验标签或训练模型。
