# 运行范围

## 可直接运行

README中的合成交易基线，以及不依赖外部数据的测试。它们覆盖时间切分、指标分母、候选构造、排序特征和推荐动作约束等实现逻辑。

依赖未发布合同与检查点的测试会明确跳过，其断言予以保留；具体目标见`export-manifest.json`。只有准备了原研究资产和分支环境后才应设置`HM_RESEARCH_ASSETS=1`启用。默认测试通过只表示公开范围内逻辑通过，不表示原始实验全部复现。

## 自行取得数据后运行

基础时间验证与数据审计。运行`hm-recsys --help`检查当前CLI入口，使用明确的截止日、抽样比例、历史长度与输出目录。全数据计算优先使用分块读取或DuckDB；资源成本取决于数据量，不能由微型示例耗时估算。

## 历史研究代码

完整推荐主干、内容模型训练、后续候选准入与融合研究依赖原实验合同、预处理表、模型和嵌入，这些产物没有发布。部分历史入口还校验当时分支、原提交祖先、时间预算与冻结证据。新仓库没有那些提交或分支，因此这些入口会拒绝运行，这是保留的研究安全约束。

迁移时把两处工作区的硬编码路径统一为本仓库根目录；没有自动重建历史合同、取消训练门槛或补造证据。私人提示附件引用已改为`docs/research-contracts/private-approval.txt`，该文件不发布；需要它的注册入口不能直接执行。

不要把历史分支检查改成无条件通过来运行实验。要复现实验，应根据自己的数据与资源重新建立合同、输入资产与训练边界，再显式适配入口。仓库中的汇总结果是历史测量，而不是安装后即可得到的承诺。

数据目录、运行产物、凭据和报告默认被Git忽略。首次公开前由仓库所有者审阅README及迁移记录；当前迁移保持远程仓库私有。
